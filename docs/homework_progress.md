# Выполнение домашнего задания №4

## Принятые решения

Пользователь выбрал **C# + Blazor WebAssembly + MudBlazor**.
Используются .NET SDK 10.0.302 и MudBlazor 9.7.0.

Основа — [существующее ТЗ](technical_specification.md), обязательные истории US-01–US-10
и [концепция 3 «План поездки»](ui_concepts/03-analytical.html).
Исходные документы проектирования сохранены как материалы ДЗ 3.

## Статус шагов

| Шаг | Результат |
| --- | --- |
| 1. ТЗ и стек | Определены стек, UI-библиотека и обязательные функции: варианты, бюджет, сравнение, параметры и хранение |
| 2. Инициализация | Созданы solution и проекты, зависимости закреплены, локальный сервер и CSS hot reload проверены |
| 3. Структура | Выделены Core, Client, компоненты и адаптер IndexedDB; основной маршрут / |
| 4. Интерфейс | Реализованы US-01–US-10, формы и состояния; вымышленный пример доступен при первом запуске и по отдельной кнопке без перезаписи данных |
| 5. Тестирование | Модульные, компонентные и браузерные проверки; найденные ошибки описаны в отчёте |
| 6. Адаптивность | Проверки 360/768/1440, масштаба 200%, клавиатуры и размеров целей |
| 7. Оптимизация | Убраны полная JSON-копия данных и повторный рендер неизменённых карточек при переключениях; измерения на 10×50 вариантах |
| 8. Оформление | Подготовлены README, отчёт, исходники тестов и скриншоты; публикацию на GitHub пользователь выполняет самостоятельно |

Фактические результаты и ограничения проверок находятся в [development_report.md](../development_report.md)
и [evidence](evidence/). Наличие локальных материалов не означает их публикацию на GitHub.

## Материалы ДЗ 2

В соседнем HT2 найдены Отчет/prompt_templates.md и Отчет/rules.md.
Структура RTCF адаптирована в [prompt_templates.md](prompt_templates.md),

и в текущий проект не перенесены. Node.js и npm для выбранного стека не требуются.

## Границы

Копирование вариантов, сортировка и отметка решения семьи не входят в обязательный MVP.
Нет аккаунтов, серверного API поездок, импорта цен и синхронизации.
