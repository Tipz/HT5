# Работа над «Вместе в путь»

Правила адаптированы из ДЗ 2 (Home Services Dashboard, Отчет/rules.md) к выбранному пользователем Blazor WebAssembly.

- Основа поведения: docs/technical_specification.md и обязательные US-01–US-10 в docs/user_stories.md.
- Стек: C#, .NET 10, standalone Blazor WebAssembly, MudBlazor, IndexedDB через небольшой JS-модуль.
- Together.Core содержит модель, расчёты и валидацию без зависимости от UI и браузера. Together.Client содержит компоненты, управление экраном и адаптер хранения.
- Не переносить из ДЗ 2 серверные EF Core/SQLite, Interactive Server, роли и авторизацию: в этом проекте их нет.
- Пользовательский ввод выводить как текст. Внешние ссылки допускают только абсолютные http/https и открываются с noopener noreferrer.
- Считать расходы в целых копейках; различать null и ноль. Даты считать через DateOnly.
- Сохранённые данные заменять в интерфейсе только после успешной транзакции. Не очищать повреждённые базы автоматически.
- При конфликте версии не терять черновик; перед его отбрасыванием спрашивать подтверждение в интерфейсе.
- UI на русском, холодная палитра концепции 3, сравнение перед карточками. Использовать MudBlazor и семантические HTML-элементы.
- Не отправлять поездки, возраст детей или заметки в сторонние сервисы; тесты и скриншоты используют вымышленные данные.
- Не менять несвязанные файлы и исходные материалы пользователя. Избегать лишних зависимостей и абстракций.
- Для нетривиальных изменений запускать подходящие тесты. Перед сдачей: dotnet build, dotnet test и браузерные сценарии.
- Документировать фактические команды, результаты и ограничения. Не выдавать неисполненные проверки за успешные.
